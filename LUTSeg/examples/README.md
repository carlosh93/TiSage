# LUTSeg Examples

This folder contains a curated pseudonymized subset produced by the scripts in
`LUTSeg/pipeline/`.

## Contents

- `Images/`: example input images.
- `Masks/`: aligned tissue masks.
- `Wound_Masks/`: aligned wound masks.
- `Masks_RGB/`: color-rendered tissue masks.
- `visualizations/`: image/mask visualizations.
- `Form/public/`: comparison images, form index, and vote template.
- `Form/anonymized_votes/`: pseudonymized responses, option mapping, tie report, and final selections.

The image, patient, response, and clinician identifiers are dataset-internal
codes rather than personal identifiers. Clinician identifiers remain
pseudonymized in the public release.
